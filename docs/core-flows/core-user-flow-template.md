# 核心用户流程模板

## 0. 模板用途
本模板用于定义“AI 电商产品图与海报生成网站”的关键体验链路，重点覆盖非专业用户从上传产品照片到下载或继续编辑的完整过程。

设计目标：
- 低门槛：用户不需要理解专业设计、修图或 AI 参数。
- 低认知负担：每一步只要求用户做一个明确选择或确认。
- 可回退：用户可以从错误、失败或不满意结果中回到上一步继续调整。
- 可验收：每个流程节点都有输入、处理、输出和失败处理。

## 2. 用户视角原则
定义流程时优先使用用户能理解的任务语言，不使用专业参数作为主路径。

| 原则 | 要求 |
| --- | --- |
| 少填 | 只让用户填写生成必须的信息 |
| 少选 | 优先提供少量清晰选项，而不是大量参数 |
| 可预览 | 关键选择前尽量给出示例、缩略图或结果预期 |
| 可修改 | 用户不满意时能回到最近一步，而不是重开任务 |
| 可解释 | 系统处理失败时说明用户可以做什么，不暴露复杂技术原因 |

## 3. 主流程模板

| 步骤 | 用户动作 | 系统处理 | 输出 | 用户下一步 |
| --- | --- | --- | --- | --- |
| 1. 上传产品照片 | 上传或拖入产品图片 | 检查文件类型、大小、清晰度和主体可识别性 | 可用图片 / 问题提示 | 继续 / 重新上传 |
| 2. 识别和处理输入 | 确认系统识别出的主体和基础信息 | 识别商品主体、背景、比例、可能用途 | 商品主体预览、可编辑信息 | 确认 / 修正 |
| 3. 选择目标输出类型 | 选择白底图、场景图、海报或其他目标 | 根据输出类型加载对应规则和所需字段 | 目标类型和必要补充项 | 补充信息 / 返回选择 |
| 4. 调整风格或模板 | 选择风格、模板、尺寸或活动类型 | 匹配模板、布局、色彩和文案结构 | 生成方案摘要 | 生成 / 返回调整 |
| 5. 系统生成结果 | 等待生成并查看进度 | 生成图片、检查基础质量、整理候选版本 | 结果预览、版本列表 | 下载 / 继续编辑 / 重新生成 |
| 6. 下载或继续编辑 | 下载结果，或继续调整局部内容 | 导出图片，或进入编辑流程 | 文件 / 编辑中的版本 | 完成 / 继续迭代 |

## 4. 输入定义模板

| 输入项 | 是否必填 | 用户理解方式 | 系统用途 | 缺失时处理 |
| --- | --- | --- | --- | --- |
| 产品照片 | 是 | 上传商品图片 | 识别主体并生成素材 | 阻止继续，提示重新上传 |
| 输出类型 | 是 | 白底图 / 场景图 / 海报 | 决定生成规则和模板 | 要求选择一个目标 |
| 商品名称 | 否 | 商品叫什么 | 辅助文案和文件命名 | 可由用户稍后补充 |
| 核心卖点 | 否 | 想突出什么 | 生成海报文案和构图重点 | 提供空白或示例引导 |
| 使用平台 | 否 | 淘宝 / 小红书 / 抖音等 | 约束尺寸、风格和规则 | 使用通用电商规则 |
| 风格偏好 | 否 | 简洁 / 高级 / 节日 / 促销等 | 匹配模板和视觉方向 | 使用默认风格 |

## 6. 失败场景模板

| 失败场景 | 可能原因 | 用户看到的处理方向 | 回退路径 | 是否阻断主流程 |
| --- | --- | --- | --- | --- |
| 图片无法上传 | 格式、大小或网络问题 | 更换图片或重新上传 | 回到上传产品照片 | 是 |
| 产品主体不清晰 | 图片模糊、遮挡、主体太小 | 换一张更清晰的产品图 | 回到上传产品照片 | 是 |
| 系统识别不准确 | 主体、品类或背景判断错误 | 让用户手动修正 | 回到识别和处理输入 | 否 |
| 输出类型信息不足 | 海报缺少活动、价格或卖点 | 提示补充最少必要信息 | 回到选择目标输出类型 | 否 |
| 模板不匹配 | 风格或尺寸不适合当前商品 | 推荐切换模板或使用默认布局 | 回到调整风格或模板 | 否 |
| 生成失败 | 生成服务异常或结果不可用 | 重试或保存当前输入 | 回到系统生成结果 | 否 |
| 用户不满意结果 | 风格、构图或文案不符合预期 | 修改风格、模板或卖点后重新生成 | 回到调整风格或模板 | 否 |

## 7. 回退路径模板

| 当前步骤 | 可回退到 | 保留内容 | 清除内容 |
| --- | --- | --- | --- |
| 识别和处理输入 | 上传产品照片 | 无 | 当前识别结果 |
| 选择目标输出类型 | 识别和处理输入 | 产品照片、识别结果 | 输出类型相关补充项 |
| 调整风格或模板 | 选择目标输出类型 | 产品照片、识别结果、输出类型 | 当前模板选择 |
| 系统生成结果 | 调整风格或模板 | 产品照片、识别结果、输出类型、风格选择 | 当前失败结果 |
| 下载或继续编辑 | 系统生成结果 | 全部输入和生成版本 | 无 |

## 8. 输出定义模板

| 输出项 | 用途 | 最低要求 | 后续动作 |
| --- | --- | --- | --- |
| 结果图片 | 用户下载或继续编辑 | 主体清晰、画面完整、符合输出类型 | 下载 / 继续编辑 |
| 版本记录 | 支持对比和回退 | 记录生成时间、模板、风格和输入摘要 | 选择版本 / 重新生成 |
| 问题提示 | 指导用户修正 | 明确指出下一步能做什么 | 回到对应步骤 |
| 模板候选 | 沉淀可复用规则 | 标记适用场景和必要输入 | 进入模板库草案 |

## 9. 非专业用户检查清单
- [ ] 用户每一步都知道自己要做什么。
- [ ] 主路径不要求用户理解专业设计术语。
- [ ] 选项数量受控，避免一次展示过多参数。
- [ ] 失败提示能给出可执行的下一步。
- [ ] 用户不满意时可以局部调整，不需要从头开始。
- [ ] 系统自动处理复杂规则，用户只确认结果和偏好。

---

## 10. 流程验收清单
- [ ] 覆盖上传、识别、选择输出类型、调整模板、生成、下载或继续编辑。
- [ ] 每个步骤都有输入、处理、输出和下一步。
- [ ] 每个关键失败场景都有回退路径。
- [ ] 输出能连接到页面设计、生成链路和测试验证。
- [ ] 流程能被拆成任务卡和 checkpoint。
