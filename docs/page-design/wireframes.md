## 概述

本文档覆盖首版 MVP 的 4 个核心页面及其全部交互状态。页面间流转关系：工作台 → 新建任务 → 生成等待 → 结果预览（→ 微调 → 导出）。

### 状态

| 状态 | 表现 |
| --- | --- |
| **默认** | 所有字段为空，平台和风格无选中，生成按钮置灰不可点击。 |
| **图片已上传** | 上传区域替换为已上传图片的缩略图预览，右上角有 ✕ 删除按钮。 |
| **表单项校验失败** | 对应字段下方显示红色提示文字（"请至少填写一条卖点"），字段边框变红。 |
| **全部必填项完成** | 生成按钮亮起，颜色从灰变为主色，可点击。 |
| **提交中** | 生成按钮显示 loading 动画 + "生成中..."，所有输入字段不可编辑。 |
| **提交失败** | 页面顶部弹出错误提示："生成失败：请稍后重试"，生成按钮恢复可点击。 |

### 输入校验规则

| 字段 | 规则 |
| --- | --- |
| 商品照片 | 必填，JPG/PNG，≤10MB，最小尺寸 400×400px |
| 卖点 1 | 必填，≤15 字 |
| 卖点 2 | 必填，≤15 字 |
| 卖点 3 | 选填，≤15 字 |
| 目标平台 | 必选 |
| 风格方向 | 必选 |

## 页面 3：生成等待

**目标**：在生图期间提供可感知的进度反馈，不让用户困惑。

```
┌──────────────────────────────────────────────┐
│  ← 返回              生成中...               │
├──────────────────────────────────────────────┤
│                                              │
│                                              │
│              ┌──────────────────┐            │
│              │                  │            │
│              │   图片占位区域    │            │  ← 先显示上传原图，
│              │   （显示原图）    │            │     生成完成后替换
│              │                  │            │
│              └──────────────────┘            │
│                                              │
│              ████████████░░░░░░  60%         │  ← 伪进度条
│                                              │
│              预计还需 15 秒...               │
│                                              │
│                    [取消]                     │
│                                              │
└──────────────────────────────────────────────┘
```

### 状态

| 状态 | 表现 |
| --- | --- |
| **生成中** | 显示原图 + 进度条动画 + 预计等待时间。进度条非精确值，按预估时间平滑前进。 |
| **超时（> 60 秒）** | 文案变为"生成时间比预期长，请耐心等待...”，进度条停在 90%。60 秒后自动显示"取消"为醒目按钮。 |
| **用户取消** | 弹出确认："确定取消本次生成吗？" → 确认后返回新建任务页，表单内容保留。 |
| **生成失败** | 进度区域替换为错误提示："生成失败：请稍后重试" + "重试" / "返回编辑" 两个按钮。不自动跳转。 |

## 页面 4：结果预览与导出

**目标**：展示生成结果，支持微调，一键导出。

```
┌──────────────────────────────────────────────┐
│  ← 返回编辑        结果预览          [导出]   │
├──────────────────────────────────────────────┤
│                                              │
│  ┌────────────────────────────────────┐      │
│  │                                    │      │
│  │        [生成的商品主图]             │      │
│  │        Amazon 2000×2000            │      │
│  │                                    │      │
│  └────────────────────────────────────┘      │
│                                              │
│  微调文字                                    │
│  ┌────────────────────────────────────┐      │
│  │ 卖点 1 字号：[—] ●●● [＋]          │      │
│  │ 卖点 1 位置：上 / 中 / 下 │ v │     │      │
│  │ 卖点 2 字号：[—] ●●● [＋]          │      │
│  │ 卖点 2 位置：上 / 中 / 下 │ v │     │      │
│  └────────────────────────────────────┘      │
│                                              │
│  ┌──────────────┐  ┌──────────────────┐      │
│  │   重新生成    │  │   保存为模板     │      │
│  └──────────────┘  └──────────────────┘      │
└──────────────────────────────────────────────┘
```

### 状态

| 状态 | 表现 |
| --- | --- |
| **首次预览** | 展示生成结果 + 微调面板（默认位置为生成时的原始值）。导出按钮可用。 |
| **微调中** | 用户改动字号或位置后，预览区域实时更新文字叠加效果（前端本地渲染，无需重新请求 API）。 |
| **点击"重新生成"** | 保持当前输入参数，重新调用 API，回到页面 3（生成等待）。 |
| **点击"保存为模板"** | 弹出命名输入框，确认后保存，toast 提示"模板已保存"。 |
| **导出中** | "导出"按钮变为 loading，完成后触发浏览器下载。 |
| **导出完成** | 下载开始后，页面中心弹出 toast："图片已导出。是否创建新任务？" + "创建新任务" / "返回工作台" 按钮。 |

### 平台尺寸映射

| 平台 | 输出尺寸 | 格式 |
| --- | --- | --- |
| 亚马逊 | 2000×2000 px | PNG |
| 淘宝 | 800×800 px | PNG |
| Shopee | 1024×1024 px | PNG |
| 通用 | 1200×1200 px | PNG |
