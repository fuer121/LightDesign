## 1. 产品一句话

帮助电商卖家将一张商品照片 + 几句卖点，在 3 分钟内变成可直接上架的专业产品主图。

## 2. 目标用户

中小电商卖家、店铺运营、内容营销人员——他们有商品图但缺乏设计能力，需要快速产出符合平台规范的素材。

## 3. 首发核心场景：商品主图生成

用户上传一张商品照片，输入卖点文案，选择平台和风格，获得一张可直接上架的专业产品主图。

**端到端流程**：
1. 用户进入工作台，点击"新建生成任务"
2. 上传商品照片（支持 JPG/PNG，≤10MB）
3. 填写卖点文案（最长 3 条，每条 ≤15 字）
4. 选择目标平台（亚马逊/淘宝/Shopee/通用）和风格方向（简约白底/场景化/促销感）
5. 点击生成，等待 10-30 秒
6. 预览生成结果，可在画布上微调文字位置和大小
7. 满意后一键导出（PNG，符合目标平台尺寸规范）
8. 该次生成自动保存为模板，下次可直接复用

## 4. 首版范围

| 做 | 不做 |
| --- | --- |
| 单张商品图上传与生成 | 批量多商品同时生成 |
| 文字叠加（卖点、价格） | 复杂多图层自由排版 |
| 4 个平台尺寸模板（亚马逊/淘宝/Shopee/通用） | 自定义任意尺寸 |
| 3 种风格方向（简约白底/场景化/促销感） | 自由 prompt 输入（首版不暴露裸 prompt） |
| 单次生成 → 预览 → 微调 → 导出 | 多次生成自动对比选优 |
| 生成历史记录（最近 20 条） | 完整素材资产管理 |
| 历史任务一键复用为模板 | 团队协作与权限管理 |
| Google/Email 登录 | 企业 SSO、多租户 |

## 5. 成功标准（可测量）

| 维度 | 标准 |
| --- | --- |
| 首次成功率 | 新用户无指导下完成首次生成并导出，完成率 ≥ 80% |
| 生成耗时 | 从点击生成到预览出现 ≤ 30 秒 |
| 输出质量 | 商品主体清晰无变形，文字可读，尺寸符合目标平台规范 |
| 复用率 | 上线后两周内，≥ 30% 的任务来自模板复用 |
